# js-folio

JavaScript portfolio experiments — early JS DOM and animation exercises.

## The problem

You are building small interactive portfolio pieces in plain JavaScript before adopting React.

## What it does

Collection of JS-powered portfolio snippets and pages — open files locally to explore.

## Install

```bash
git clone https://github.com/irachrist1/js-folio.git && cd js-folio
# Open individual HTML files in browser
```

## How it works

- **Vanilla JS interactions.** DOM manipulation and events without framework magic.
- **Portfolio experiments.** Stepping stones toward [3D-Portfolio-2023](https://github.com/irachrist1/3D-Portfolio-2023) and later [portfolio](https://github.com/irachrist1/portfolio).
- **Learning archive.** Not maintained — historical JS practice.
